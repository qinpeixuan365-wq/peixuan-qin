# 答辩准备

| 评委可能会问 | 回答要点 |
| --- | --- |
| 为什么一个中国团队做孟加拉？ | 这条赛道就是孟加拉。方案只用全球公开数据，任何人都能复现；落地通过赛道合作方和当地农技员。 |
| GloFAS 是模拟流量，可信吗？ | 我们检验的是预测逻辑：1997 年以来 29 个旱季逐年回测，并和照往年经验正面比较；FFWC 官方实测水位的变化方向也和模型一致（10 月 13 日到 19 日实测下降 0.97 米，GloFAS 下降 29%）。试点期再用实测流量和盐度标定。 |
| 为什么不直接预测盐度？ | 实测盐度数据属于孟加拉政府，目前不公开。2024 年的研究用 86 个站 30 年的数据证明盐度主要由上游来水控制，所以先预测这个公开可得的驱动因子。 |
| 为什么不用卫星直接判断盐度？ | 孟加拉沿海的研究显示，9 种卫星盐度指数和实测土壤电导率几乎不相关（R² 最高约 0.02）。卫星影像用来看清河网、虾塘和红树林；盐度靠手持盐度计实测；淹水范围可以在试点阶段用 Sentinel-1 雷达做。 |
| 咸水上溯的 50 天是怎么来的？ | 估计值，网页上写明了。GloFAS 的跌破日一般在 1 月中下旬，按 50 天倒推，推荐插秧期正好落在 BRRI 试验产量最高的 12 月中下旬，开花在 3 月中旬前；试点时用实测盐度标定。 |
| 预测错一次，农户就不信了怎么办？ | 一是只给区间不给单一日期，八成区间回测命中 81% 到 85%，事先讲清大约每五季有一季会落在区间外；二是宁早勿晚，排期另给按区间早端倒推的求稳日期（今年 11 月 15 日前落谷、12 月 25 日前插秧），蓄水和选耐盐品种这些建议无论哪天用完甜水都不吃亏；三是每天更新、越临近越准（提前 15 天误差 2.3 天），并公开历年战绩；四是经农技员和清真寺喇叭等可信渠道传达，试点期用手持盐度计实测，出了偏差公开说明原因。 |
| 跌破日这么规律，模型有什么用？ | 跌破日每年在 1 月 13 日到 2 月 5 日之间，照往年经验平均差 5 天左右；模型提前 15 天能把误差降到 2.3 天，还能给出“今年会不会跌破”的概率（29 季里有 3 季整季没跌破）。更重要的是后面的决策：排期、选种和存水量都从这个日期倒推。 |
| 为什么选 12 个相似年份？ | 事先固定，没有调参。只用来水最像今年的年份，避免把很湿或很干的年份硬套过来。 |
| 数字能复现吗？ | 能。网页底部可以导出全部数据，仓库里的 scripts/backtest.py 用同一方法离线重算，结果和网页完全一致。 |
| FFWC 数据为什么是快照？ | FFWC 官方 API 需要注册（api.support@bwdb.gov.bd），比赛期间先放入 10 月 19 日官方发布的实测和预报，正式版注册后每天自动同步。 |
| 条约话题会不会敏感？ | 我们只描述流量统计规律，不评价两国的水资源安排；提到条约到期，只是说明明年不确定性更大。 |
| 为什么演示里 AI 不是 DeepSeek？ | DeepSeek 官方要求 Key 不放在网页里，也不允许网页直接调用。正式部署时通过服务器中转调用 DeepSeek；演示版无 Key 时走免费通道，规则模板保证不断线。 |
| 谁来付钱？ | 农户免费；孟加拉农业推广局（DAE）、NGO 和气候适应项目采购区域服务。静态网页加公开数据，运营成本主要是短信费。 |
| 能推广到哪里？ | 换一个河流取点和气象取点，就能用于湄公河、伊洛瓦底江等其他三角洲。 |
